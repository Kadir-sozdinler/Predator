# Predator Antivirüs 🛡️

Predator, sisteminizi kötü amaçlı yazılımlara, fidye yazılımlarına (ransomware) ve sıfırıncı gün (zero-day) tehditlerine karşı aktif olarak korumak için tasarlanmış, hafif ve yüksek performanslı bir antivirüs motorudur.

## 🚀 Özellikler

* **Gerçek Zamanlı Koruma (Real-Time Protection):** Dosya sistemi etkinliklerini arka planda kesintisiz izler ve şüpheli işlemleri anında engeller.
* **Sezgisel Analiz (Heuristics Engine):** Henüz veri tabanında bulunmayan bilinmeyen tehditleri, davranışsal analiz yöntemleriyle tespit eder.
* **Düşük Kaynak Tüketimi:** Gelişmiş optimizasyonu sayesinde eski sistemlerde bile CPU ve RAM'i yormadan çalışır.
* **Çevrimdışı Tarama Desteği:** İnternet bağlantısı olmasa dahi yerel tehdit veri tabanı ile tam kapsamlı tarama yapabilir.

## 📋 Sistem Gereksinimleri

* **İşletim Sistemi:** Windows 10/11, Linux (Ubuntu 20.04+, Debian 11+), macOS 12+
* **İşlemci:** x86_64 veya ARM64 mimarili 1 GHz ve üzeri işlemci
* **RAM:** Minimum 512 MB (Önerilen: 1 GB)
* **Depolama:** 200 MB boş disk alanı
